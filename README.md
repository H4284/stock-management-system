# SPMES - Sales & Employee Management System

A WinForms desktop application for managing employees, products, orders, and sellers.

## Features
- Employee management
- Product management
- Order tracking
- Seller management
- Admin and User dashboards

## Tech Stack
- C# .NET Framework 4.7.2
- WinForms
- Entity Framework 6
- SQL Server

## Requirements
- Visual Studio 2019+
- SQL Server (local)
- .NET Framework 4.7.2

## Setup
1. Clone the repository
2. Open `SPMS_.sln` in Visual Studio
3. Update connection string in `App.config` if needed
4. Run the application
